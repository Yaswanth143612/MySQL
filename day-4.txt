--- DML COMMANDS ----

INSERT:
-->it is used to insert the values to the columns and rows which we want to add it can be added using insert operation into the existing data base.
SYNTAX:
insert into tablename(column-name1,column-name2


drop:
  -->it removes the table or object.
  -->table-structure+data will be droped.
  -->table structure removed
  -->performance is slow (due to full removal)

delete:
  -->removes a specific rows from a table
  -->specific rows based on condition.
  -->table structure intact
  -->performance is slower(row-by-row)
truncate:
  -->removes all rows and keeps structure.
  -->all rows removed
  -->table structure intact
  -->performance is fast(bulk-deletion)
