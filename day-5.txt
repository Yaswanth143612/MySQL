==== CONSTRAINTS ===

constraints are rules applied to a table columns in MySQL to ensure that only valid under accurate data is stored in  the data base.

--> Insimple words:
 constraints = rules that control the data entered into a table.

why do we use constraints?

constraints are used to:
1.maintain data integrity
2.prevents invalid data entry.
3.Avoid duplicate records.
4.ensures relationships between tables,
5.make the database reliable and consistent.


Types of constraints:

1.not null key:

    The not-null constraints ensures that a column cannot contain "NULL"(empty)values.Every row must have a value for that column.
    -- Not-Null doesn't allow null values.

2.unique key:

    The unique key constraint ensures that all values in a column are different.
    Duplicate values are not allowed.

3.*** primary key: ****

    Primary key is the combination of both  Not-null and Unique Key constraints.
     
4.composite key:

    Composite key constraint means the combination of more than one primary key .
    If we applied more than one column primary key then we should go for composite key constraint.
    It can applicable only for table-level not at column-level.

5.***foreign key:****
       A foreign key creates a relationship b/w two tables.
       It ensures that value in the child table must already exists in the parent table.
  
==> Referencial actions:
     Referencial defines what happens to child table data when parent table data is updated or deleted.
     ---> ON DELETE CASCADE, ON UPDATE CASCADE
     ---> ON DELETE SET NULL, ON UPDATE SET NULL.      
    
6.default key:

   The default constraint automatically assigns a predefined value if no value is provided during insertion.

7.check constraint  key:
   
    The check-constraints ensures that values satisfy a specified condition before insertion or update.



***foreign key:****
       A foreign key creates a relationship b/w two tables.
       It ensures that value in the child table must already exists in the parent table.
