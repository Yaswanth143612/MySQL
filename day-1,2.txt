==== SQL ====

SQL(structured query language):
 SQL is a structured query language that is used to communicate.
it is a standardized programming language specially designed for managing and manipulating relational databases.It provides a declarative syntax that allows users to define what data they want retrive,insert,update or delete without specifying exactly how database should execute these operations.

===SQL COMMANDS ==
1.DDL: Data Definition Language.
   Defines and modifies the structure of database objects(tables, schemas,indexes)
  they are 5 commands:
   1.CREATE: CREATES  anew data bases objects such as tables,database,views,indexes or triggers .. etc
    ---> How to create database/schema?
        syntax:
             CREATE DATABASE database-name;
                or
             CREATE SCHEMA database-name;
    --->How to create table?
        syntax:
             CREATE TABLE table-name(
             column-name datatype(size) constraint,
             column-name datatype(size) constraint,
             column-name datatype(size) constraint,
                     |
                     |
             column-name datatype(size) constraint,

 
     2.Drop: Permanently  deletes an existing database objects(table,database,index,views)along with its data and structure.
     --->How to drop database/schema?
         syntax:
           drop database database-name;
                  or
           drop schema database-name;
     --->How to drop table?
         syntax:
           drop table table-name;

   3.ALTER:By using alter command we can modify the existing table structure.
   
   4.TRUNCATE:
   5.RENAME:

2.DML: Data Manipulation Language:
   It manages data stored within the database objects(insert,update,delete)

3.DCL: Data Control Language.
   It manages permissions and access control on database objects.

4.TCL: Transaction Control Language.
   It manages transaction to maintain data integrity.

5.DQL: Data Query Language
   It is used to fetch/retrieve data from the database.
