Clauses
============

In MySQL clauses are used to control how data is filtered,grouped,sorted or modified in sql
Queries.
they make SQL Statements more meaningful and powerful

Where clause
=============

filter records based on specified conditions where clause can be used as comparision operators,logical operatators and...etc operators.

syntax
======
select column1,column2...from table where condition;

Group by clauses
===============

the group by clause is used to group rows having the same values in one or more colums, it is commonly used with aggregate fuctions such as min(),max(),sum(),count(),avg()

syntax
========

select column-name,aggreage_functions(coloumn-name) from table-name group by column-name;

Having clause
===========

The having clause is used to filter grouped records after group by clause. it is similar to where but it works on grouped insted of individual rows.


syntax
---------

select coloumn-name,aggreage_fuction(coloum-name) from table name group by coloum-name
having condition;

order by clause
==============

the order by clause is used to sort the result set in ascending(ASC) or desc

syntax
=========

select column-name from table-name order by column-name;
